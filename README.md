# موقع تقييم محمد الساخي — GitHub Pages + Supabase

الموقع ثابت ويمكن استضافته على GitHub Pages، بينما تحفظ Supabase التقييمات والتعليقات والبلاغات.

## الملفات
- `index.html` — الصفحة العامة.
- `admin.html` — صفحة إدارة المشرف.
- `app.js` — وظائف الصفحة العامة.
- `admin.js` — تسجيل دخول وإدارة المشرف.
- `style.css` — التصميم المتجاوب للهاتف والكمبيوتر.
- `config.js` — Project URL والمفتاح العام.
- `mohamed-sakhi.png` — صورة محمد الساخي.
- `supabase.sql` — إنشاء الجداول والسياسات.

## إعداد Supabase
1. افتح SQL Editor.
2. نفّذ `supabase.sql` كاملًا.
3. ضع Project URL وPublishable/anon public key في `config.js`.
4. لا تستخدم `service_role` أو Secret key في الموقع.

## إعداد حساب المشرف
1. في Supabase افتح Authentication → Users.
2. أنشئ مستخدمًا للمشرف بالبريد وكلمة المرور.
3. انسخ UUID الخاص بالمستخدم.
4. في SQL Editor نفّذ، مع استبدال UUID:

```sql
insert into public.admins (user_id)
values ('ضع-UUID-هنا');
```

بعد ذلك يمكن للمشرف الدخول من `admin.html`.

## ماذا يستطيع المشرف؟
- مشاهدة التعليقات المنشورة والمخفية.
- إخفاء تعليق أو إعادة إظهاره.
- حذف تعليق نهائيًا.
- مشاهدة البلاغات.
- تعديل اسم الشخص ورابط الصورة.

## مهم قبل الإطلاق العام
لأن الموقع يسمح للزوار بنشر محتوى عن شخص، يُنصح بإضافة CAPTCHA/Turnstile وRate limiting، ووضع سياسة خصوصية وشروط استخدام، وآلية واضحة للتعامل مع المحتوى المسيء أو البيانات الشخصية.
